# 99百词斩键盘连接器

> 还有3000个单词啊。。。。。
>
> 一次记录我的知识领域踏向手机端自动化的开端

这是一个可以让电脑将键盘信号转发到手机百词斩中的工具，搭配安卓模拟器体验更佳

## 写在前面

百词斩为啥不能外接蓝牙键盘呀呜呜

## 安装

下载或`clone`这个仓库，安装所需要的库

~~~shell
pip install -r requirements.txt
~~~

安装好`uiautomator2`后，请将您的手机连接到您的电脑，并确定adb可以连接到您的手机（别忘了打开usb调试并允许RSA指纹）

执行这串代码，`uiautomator2`会安装必要的软件到您的电脑

~~~shell
python -m uiautomator2 init
~~~

如果需要，请自寻通过wifi连接的方式

## 使用

使用时，请将手机通过恰当的方式连接到电脑，运行程序

~~~shell
python main.py
~~~

程序自检通过后，请按照程序说明开始使用程序吧

使用时按下<kbd>F2</kbd>可以切换模式

在**四方格模式**下，<kbd>W</kbd>，<kbd>E</kbd>，<kbd>S</kbd>，<kbd>D</kbd>对应左上，右上，左下，右下的答题框，回车为下一题的按钮
